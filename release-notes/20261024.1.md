AVXEmu now has an experimental Linux port, alongside fixes and stronger testing for macOS.

- **Linux support.** Build `libavxemu.so` from source for x86-64 Linux with glibc, then load it
  with `LD_PRELOAD` or link it into a program. Like the macOS version, it requires SSE4.2 and
  AVX with operating-system support. Musl is not supported yet; this release's installer
  remains macOS-only.
- **A shared emulator across platforms.** macOS and Linux use the same instruction emulation,
  scanning, patching and cache logic, with separate code for each platform's executable
  format, memory operations and signal handling.
- **More accurate BMI emulation.** The fast register-operand path now preserves CPU flags
  that the emulated instruction is supposed to leave unchanged.
- **Testing on Mavericks itself.** Before publication, CI installs the macOS package in a
  Mac OS X 10.9.5 virtual machine and tests the installed library. Linux tests also run under
  emulated CPUs with genuinely missing instructions, as well as on AVX2 hardware.

Checked on a physical AVX-only Mavericks Mac: the candidate library passes its self-test
and runs Claude Code 2.1.306, including manually tested authenticated turns. Cold and warm
`--version` and `--help` checks also match the previously installed library.

The Linux port passes its automated tests, but has not yet been validated with real
applications on physical AVX-only hardware. Treat it as experimental, including for Claude
Code on Linux.
