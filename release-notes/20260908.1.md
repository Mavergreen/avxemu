The first AVXEmu release from Mavergreen, and a repackaging only. Its source is exactly that of
the `libavxemu.dylib` [mavericksforever.com](https://mavericksforever.com/claude/) serves
(checked 2026-09-27): built on 10.9, it compiles byte-identical objects, which reproduce that
dylib byte for byte when linked without the SDK, as the old `build.sh` linked them. This
release's copy is cross-built in CI with a current Apple clang against the pinned 10.9 SDK, so
its bytes differ. Its behaviour is checked by the hermetic and replay tests
([PROVENANCE.md](https://github.com/Mavergreen/avxemu/blob/main/PROVENANCE.md)).

Checked on Mac OS X 10.9 without AVX2: the released `libavxemu.dylib` passes its self-test
(`AVXEMU_SELFTEST`) and runs Claude Code. Its `hardware` tests pass on an Intel Mac with AVX2,
FMA and BMI.

It installs to `/usr/local/mavergreen/avxemu/lib/libavxemu.dylib` with the install name
`@rpath/libavxemu.dylib`, and keeps itself up to date. An installer that wants only the
dylib can take it out of this package with
[contrib/extract-libavxemu.sh](https://github.com/Mavergreen/avxemu/blob/main/contrib/extract-libavxemu.sh).
